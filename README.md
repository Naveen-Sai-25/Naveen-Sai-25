# 📌 Featured Projects

## 📡 LoRa-Based GPS Tracking System

🚀 Developed an offline long-range GPS tracking and emergency communication system using LoRa SX1278 and NEO-6M GPS modules.

### 🔹 Features
- Real-time GPS location tracking
- Long-distance communication using LoRa
- OLED display monitoring
- Flask web dashboard
- OpenStreetMap live visualization

### 🛠️ Technologies Used
`Arduino C/C++` `Python` `Flask` `LoRa` `GPS` `ESP32`
